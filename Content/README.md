# Content Structure

تنظيم المحتوى يعتمد على مجلد مستقل لكل سورة:

- `Content/<surah-id>-<surah-name>/`

مثال:

- `Content/016-النحل/`

## ترتيب الملفات داخل كل سورة

الملفات مرتبة تصاعديا بحسب تطور الفهم داخل المحادثات:

- `01-...md`
- `02-...md`
- `03-...md`
- ...

## الحالة الحالية

تم تجهيز سورة `016-النحل` بالملفات التالية:

- `01-نظرة-عامة.md`
- `02-الخروج-من-البطون.md`
- `03-المراحل-البرهانية.md`
- `04-المرحلة-الثانية-تفصيل.md`

المرجع المنهجي العام المشترك بين السور موجود في:

- `Process/Instructions.md`
