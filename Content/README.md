# Content Structure

تنظيم المحتوى يعتمد على مجلد مستقل لكل سورة:

- `Content/<surah-id>-<surah-name>/`

مثال:

- `Content/016-النحل/`

## ترتيب الملفات داخل كل سورة

الملفات مرتبة تصاعديا بحسب تطور الفهم داخل المحادثات:

- `01-...md`
- `02-...md`
- `03-...md`
- ...

## الحالة الحالية

تم تجهيز سورة `016-النحل` بالملفات التالية:

- `01-مدخل-السورة.md` — نظرة عامة، محور الخروج من البطون، وخريطة المراحل البرهانية
- `02-المرحلة-الأولى-(١-٢٢)-تفصيل.md`
- `03-المرحلة-الثانية-(٢٣-٥٠)-تفصيل.md`
- `04-المرحلة-الثالثة-(٥١-٦٧)-تفصيل.md`
- `05-المرحلة-الرابعة-(٦٦-٧٨)-تفصيل.md`
