# QuranContext

مشروع لدراسة السور القرآنية دراسة سياقية وحجاجية، يعتمد على تحليل المحادثات مع الذكاء الاصطناعي وتحويلها إلى ملفات منظمة قابلة للمراجعة والتطوير.

## هيكل المشروع

```
Content/        — ملفات التحليل والتدبر، مجلد لكل سورة
Chats/          — المحادثات الأصلية المحفوظة للمرجعية التاريخية
Process/        — المنهجية والتعليمات وذاكرة المشروع
```

## المرجع المنهجي

المنهجية العامة المشتركة بين السور موجودة في:

- `Process/Instructions.md`
